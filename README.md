# dev-config
Personal configuration files for Neovim and tmux.

## macOS quick start

See [DOWNLOADS.md](DOWNLOADS.md) for the full MacBook setup checklist.

```sh
git clone https://github.com/CarlosFortoul/dev-config.git ~/dev-config
cd ~/dev-config
bash ./dev-env.sh -l
```

The load command copies `nvim/` and `tmux/tmux.conf` into `~/.config`.
